1. oracle assistance is explicit, not hidden;
2. reference depth cannot be inserted as metric foreground geometry;
3. the background scaffold is exported separately from foreground reconstruction;
4. the procedural `tabletop_cloth` fixture is used — no false `.blend` provenance;
5. local FSG is reused rather than copied/redefined;
6. oracle redirects and total per-object fixations are bounded;
7. the manifest explicitly denies autonomous discovery/controller claims;
8. final observer-only and composite/reference products remain distinguishable;
9. the demo produces a timeline, with MP4 optional on `ffmpeg` availability.

Runtime checks should additionally prove accepted foreground xyz comes from the stereo measurement array, record raw-vs-accepted counts per fixation, and verify that background points never enter foreground point totals.
