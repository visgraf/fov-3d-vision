# FSG4c Chat-side checks

This record covers only checks runnable without the workstation Blender/Cycles environment. It is not an FSG4c scientific result.

The handoff is additive: it creates `fsg4c_*` tools/docs and leaves FSG4a/b records and tools intact. The existing `fsg4_policy.py` and `fsg4_metrics.py` are reused rather than forked.

Prospective design changes relative to FSG4b are limited to: fresh fixtures/seeds; per-fixation novelty/new-surface and minimum coverage-gain conditions become descriptive rather than validity gates; residual closure is reported descriptively. No replacement novelty threshold is introduced. The active policy, fixed scan, exact paired artifact reuse, FSG1 instrument, FSG3 fusion radius, AUC definition and aggregate thresholds remain unchanged.

Local checks performed by Chat are reported in `FSG4C_INCREMENT4_CHECKS.md` outside the repository handoff.
